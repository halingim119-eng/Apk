# 혜원 봇 (카카오톡 접근성 서비스)

1. 이 폴더 전체를 GitHub 저장소에 올리기 (비공개 저장소 추천)
2. Actions 탭 → Build APK → 실행이 끝나면 Artifacts 의 hyewon-bot-apk 다운로드
3. 압축을 풀어 app-debug.apk 설치 (이전 버전 위에 그냥 덮어 설치됨 - app/debug.keystore 를 지우지 마세요)
4. 앱을 열어 API 키 입력 → 저장 → 접근성 설정에서 '혜원 봇' 켜기
5. 알림 접근 설정에서 '혜원 봇 알림 답장' 켜기 (스크립트 전송용. 안드로이드 13+ 는 앱 정보에서 '제한된 설정 허용' 먼저)
6. 카톡에서 채팅방을 열어 둔 상태(화면 켜짐)에서 동작

## 알림 답장(스크립트) 전송
방마다 카톡 알림이 한 번이라도 오면 그 방의 '답장' 기능이 저장돼서, 이후엔 입력창을 쓰지 않고 바로 전송.
아직 저장 안 된 방은 자동으로 입력창 방식으로 보냄.

## /cmds 패널
- 입력창에 /cmds 를 치면 즉시 패널이 뜸
- 패널 색은 카톡 입력창 색을 읽어서 한 색 계열로 맞춤 (안드로이드 11+)
- '반복 켜짐' + 간격(초) + 횟수(비우면 무한) → 반복 시작. 화면 오른쪽 위 '■ 반복 중지' 를 누르면 멈춤
